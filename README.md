# routechord

Route CSV/TSV chord tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/routechord/

## Install / run

```bash
git clone https://github.com/theworker02/routechord.git
cd routechord
node src/cli.js
node --test
```
